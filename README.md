# IntelliCheck AI

## AI-Driven Plagiarism Intelligence for Assignments

### Problem Statement
Academic institutions face increasing difficulty in detecting nuanced forms of plagiarism, especially when assignments are paraphrased or generated using AI tools. IntelliCheck AI helps identify suspicious submissions through contextual academic integrity analysis, AI-content assessment, similarity detection, and risk classification.

---

## Project Overview

IntelliCheck AI is an AI-powered academic integrity assistant built using IBM watsonx technologies. The system analyzes assignment submissions and generates structured Academic Integrity Reports containing:

- Writing Quality Analysis
- AI Content Assessment
- Similarity Analysis
- Risk Classification
- Suspicious Indicators
- Faculty Recommendations
- Final Verdict
